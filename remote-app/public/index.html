⚙️ Cài đặt kết nối TV LG

Đang để trống. Bạn hãy kiểm tra IP trên TV và điền vào đây.
Bấm nút "🔍 Quét IP" để tự động tìm IP TV mà không cần tra cứu thủ công.
📌 Cách tìm IP & MAC trên TV LG:
  1. Bấm nút Cài đặt (Bánh răng) trên remote TV.
  2. Chọn Tất cả cài đặt (All Settings) → Mạng (Network) → Kết nối Wi-Fi.
  3. Chọn Cài đặt Wi-Fi nâng cao (Advanced Wi-Fi Settings) để xem Địa chỉ IP và Địa chỉ MAC.
  4. Lưu ý quan trọng: Vào mục Thiết bị (Devices) → Thiết bị ngoài → Bật "LG Connect Apps" (hoặc Kết nối ứng dụng điện thoại).
